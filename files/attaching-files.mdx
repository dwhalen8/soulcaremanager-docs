---
title: "Attaching files"
description: "Add documents to a counselee's record, a note or a session, and how they're protected."
---

A file belongs to whatever it's attached to: a counselee's record, a case, a note or a session. The people who can see that record can see the file; nobody else can.

## Attach a file

On the counselee's **Files** tab (or under a note or session), drag the file onto **Attach a file**, or click **Choose a file**.

*PDF, Word, Excel, OpenDocument, text, CSV or an image · up to 25 MB*

## Reading and downloading

- **Preview** opens a PDF or image in a window, without downloading it.
- **Download** saves a copy to your computer.

Every file is served only to someone signed in who can see what it's attached to. There's no public link to a file, ever, and a file is never attached to an email.

## How files are protected

Each file is encrypted with its own key before it's stored, and decrypted only as it's sent to someone allowed to read it. Reading a file is recorded in the audit log like any other read of the record.

An administrator who opens a counselee's files gives a reason first, and the counselors on the record are told who read them and why.

## Removing a file

**Remove** takes a file off the record it's attached to. It isn't destroyed: it stays in your practice's records. The one exception is a file attached to a draft note, which goes with the draft if the draft is discarded.

## Library files

A file attached to a resource in the library is library material, not part of anyone's record. A file is one or the other, never both. See [The resource library](/resources/the-resource-library).
