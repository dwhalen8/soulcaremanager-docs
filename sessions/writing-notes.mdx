title: "Writing notes"
description: "Notes beside the record, saved as you type, signed when you're done."
---

A **note** is your written record about a counselee outside a session's own fields: a case formulation, a phone call, something you want to remember. Notes live on the record's **Notes** tab.

## Start a note

Click **New note** at the top of the counselee's record (or press <kbd>⌘K</kbd> and type *New note for…*). If the counselee is on more than one of your cases, you're asked which case the note is for.

The note opens as its own page, with the record's details in a side panel beside it, so you can read their intake, homework or earlier notes while you write.

## What a note holds

- **Title**
- **Format**: free-form, or a structure such as SOAP, DAP or GIRP. A format adds headings to write under. It never limits what you write.
- **Tags** and **Scripture references**, which you can search and filter by later.
- The note itself, and any attachments.

The note saves as you type. If it was changed in another tab or on another device after you opened it, the page shows that version beside yours instead of overwriting either.

## Who can read it

*Only the counselors on this case can read the note.* An administrator can read it only by giving a reason, which is recorded. See [Who can see what](/privacy/who-can-see-what).

## Drafts and signing

Until you sign it, a note is a draft. An unsigned note waits on **Today** (*Unsigned · written … ago*, with **Sign**), and you can throw a draft away entirely with **Discard draft**.

When it says what you want it to say, click **Sign**. Any unsaved changes are saved first, then the note is signed with them.

<Warning>
  Signing locks this note permanently. It can't be edited, unsigned or deleted afterwards.
</Warning>

A signed note offers **Add addendum** for anything you need to add or correct, and you can still attach files to it. See [Signing and corrections](/sessions/signing-and-corrections).
